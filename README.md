# 无忧 Winlator（无忧win虚拟机）

> **非官方修改版**。本项目基于开源项目 [Winlator](https://github.com/brunodev85/winlator)
> 进行二次开发，与上游作者无隶属关系，不代表上游立场。

在 Android 上通过 Wine + Box86/Box64 运行 Windows 应用程序的修改版本，
在上游基础上增加了中文本地化、UI 增强与虚拟键盘接入。

## 二、二改内容

### 1. 中文本地化
- 简体 / 繁体完整字符串（取自上游繁体与简体资源，共 470 条）
- 应用内语言切换（设置 → 语言，切换后自动重启生效）
- 容器内 Wine 环境变量强制 `zh_CN.UTF-8`
- 中文字体注入（WenQuanYi Micro Hei / 微软雅黑）与注册表字体替换

### 2. UI 增强
- 18 个界面转场动画（`wl_*` 系列）
- 列表错峰入场动画
- 启动闪屏、入口横幅、容器 HUD 组件
- 使用教程界面（首次启动可查看）

### 3. 虚拟键盘接入
- 鼠标移到输入框（X11 光标变为 I-beam）时弹窗询问是否调出键盘
- 菜单 →「键盘」手动调出
- 右下角悬浮球调出
- 文本经 `InputConnection` 采集后，通过 X11 keysym 注入容器

### 4. 其他
- 首次启动免责与开源声明弹窗
- 崩溃日志落盘（便于反馈问题）
- 容器桌面中文快捷方式（浏览器 / 应用商店 / 记事本 / 任务管理器等）

## 三、已知问题

> 诚实声明：虚拟键盘的**文本注入**部分尚未完全稳定，正在修复。

| 问题 | 现象 | 状态 |
|---|---|---|
| 键盘输入字符丢失 | 只输入第一个字，后续字符未进入容器 | 修复中 |
| 输入流向错误窗口 | 文字进入文件管理器而非目标窗口 | 修复中（焦点跟随） |
| 关闭键盘后仍输入 | 键盘关闭但仍在接收输入 | 已部分修复 |
| 中文候选串泄漏 | 拼音组合过程被误发 | 已修复（组合态过滤） |

**临时应对**：先点击目标窗口内部使其获得焦点，再调出键盘输入。

## 五、源码说明

由于上游在 v11.1.0 之后不再提供完整应用源码，本项目的对应源代码形态为：

- `source/smali/`：基于发布版 APK 反编译得到的**完整 smali 源码**，
  这是构建本分发包所需的等价源代码，可直接汇编回 dex
- `source/java-new/`：本项目新增的独立文件（以 Java 编写，便于阅读与维护）
- `res/`、`AndroidManifest.xml`：资源与清单，均为构建所需

任何人可依据 [BUILDING.md](BUILDING.md) 从这些源码完整重建出功能相同的 APK。
